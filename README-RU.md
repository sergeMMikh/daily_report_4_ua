# Daily Activity Report — портативная версия для Windows

**Язык:** [Português](README.md) · **Русский** · [English](README-EN.md)

Автономное приложение для Windows 10/11, предназначенное для ведения ежедневных отчётов и подготовки текста на европейском варианте португальского языка. Достаточно скачать один исполняемый файл, поместить его в доступную для записи папку и запустить. Установка Python, PostgreSQL и дополнительного установщика не требуется.

## Скачать

[Скачать `DailyReport.exe`](https://github.com/sergeMMikh/daily_report_4_ua/raw/refs/heads/main-win/dist/DailyReport.exe)

Windows SmartScreen может показать предупреждение, поскольку исполняемый файл не подписан цифровым сертификатом. Перед запуском можно ознакомиться с исходным кодом в этом репозитории. Если вы доверяете проекту, выберите **Выполнить в любом случае** в окне SmartScreen.

## Возможности

- локальный интерфейс на португальском, русском и английском языках;
- португальский язык по умолчанию;
- ввод отчёта с датой и временем;
- необязательный автоматический перевод с русского или английского на европейский вариант португальского через API OpenAI;
- ручной ввод португальского текста, если автоматический перевод недоступен;
- сортировка сохранённых записей по времени;
- экспорт в Excel за последние семь дней, текущий месяц или выбранный год;
- локальное хранение данных в JSON-файлах UTF-8;
- отсутствие внешней базы данных и установленного Python;
- доступ только с локального компьютера по адресу `http://127.0.0.1:8765`.

## Первый запуск

1. Скачайте `DailyReport.exe`.
2. Поместите файл в доступную для записи папку, например `Документы\DailyReport`.
3. Запустите исполняемый файл.
4. Приложение откроется в браузере по умолчанию по адресу `http://127.0.0.1:8765`.

При первом запуске рядом с EXE автоматически создаются два файла:

- `config.json` — API-ключ OpenAI и выбранный язык интерфейса;
- `reports.json` — сохранённые отчёты.

Не размещайте исполняемый файл в `Program Files`: приложению необходимо создавать и обновлять файлы в своей папке.

## Автоматический перевод

Автоматический перевод необязателен. Закройте приложение, добавьте API-ключ OpenAI в `config.json` и запустите программу снова:

```json
{
  "openai_api_key": "YOUR_API_KEY",
  "language": "pt"
}
```

Поддерживаемые значения языка: `pt` — португальский, используется по умолчанию; `ru` — русский; `en` — английский. При выборе языка в интерфейсе новое значение сохраняется в `config.json`. Без API-ключа португальский текст можно вводить вручную.

Не передавайте и не публикуйте заполненный `config.json`: он содержит ваш API-ключ.

## Данные и резервное копирование

Все отчёты хранятся в файле `reports.json` рядом с EXE. Для резервного копирования или переноса данных закройте Daily Activity Report и скопируйте `reports.json` вместе с исполняемым файлом. Это обычный читаемый JSON-файл в кодировке UTF-8.

## Сборка из исходного кода

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-build.txt
.\build.ps1
```

Готовый исполняемый файл будет создан по пути `dist\DailyReport.exe`.

